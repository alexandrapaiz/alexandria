# context-window-engineering: consumer reports

The lane is open and empty. File as `YYYY-MM-DD-<consumer>.md` against the
contract in
[skills/_validation/reviews/README.md](../../_validation/reviews/README.md).

Most wanted. Every section of this skill rests on claim and paper provenance
alone, so any report at all is new information. In priority order:

- **The read-once protected region.** The regime boundary is the paper's, the
  prescription is ours and untested anywhere. Anyone who has built a durable
  facts region into a compaction step should say whether it was worth the
  plumbing.
- **Give history to the planner, not to the executor.** The furthest
  generalisation here and the one measured only on robots. A report from a text
  or code agent is the evidence this section does not have.
- **The null arm.** If you ran your ranking heuristic against random selection
  at the same budget, the result is worth a report whichever way it went. A
  report where the heuristic won would narrow the strongest claim in the file,
  which is exactly the kind of report this lane is for.
