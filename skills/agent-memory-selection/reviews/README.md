Most wanted. Every section rests on claim and paper provenance alone, and this
skill has no differential screen, so any report at all is new information. In
priority order:

- **The keep ratio on a real deployment.** The quarter-of-candidates threshold
  is this seat's reading of a two-point curve, not a measured breakpoint. Anyone
  who has a production retrieval path should report their own ratio and whether
  the rerank's value moved the way delta 2 says. A report where it did not is
  the most useful thing this lane could receive.
- **Extraction's premium outside LoCoMo.** The 3-point bound is one benchmark
  family with model-generated dialogue. A report from a product whose memory
  holds real user conversations, with the two arms at matched tokens, is the
  evidence delta 1 does not have.
- **Whether abstention regressed for you.** Delta 3 is one table on adversarial
  questions. Anyone who shipped a reranker into a memory read path and watched
  support tickets should say whether the assistant started answering questions
  nobody asked it, and whether the nothing-relevant option in step 3 helped,
  since that step is ours and untested anywhere.
- **The cut module.** If you built the typed control plane on the write path,
  report whether separating candidate discovery from relation judgment actually
  kept controller cost off memory size. That decides whether the queued second
  skill is worth writing.
