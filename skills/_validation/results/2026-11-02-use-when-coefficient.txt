What the two papers say
  arXiv:2602.05366: keeps the when-to-use field, drops example-usage. Having the clause is supported.
  arXiv:2510.22670: the field's learned weight runs 0.269x to 1.363x of the description's,
    median 0.695x, below the description in 5 of 6 cells.
  ours: 1.25x, which is ABOVE the description and inside the published range.
    So the clause is supported, a constant is ruled out in either
    direction, and central tendency runs the opposite way.

The asymmetry the boost is actually applied through
  stem_count_as_shipped  library 0.7963, panel 0.9441, ratio 0.8435x, trips True
  idf_mass_as_scored     library 0.8048, panel 0.9426, ratio 0.8538x, trips True
  tolerance 1.15x. The gate checks the stem count and the engine multiplies
  idf mass, so the gate watches a different number from the one the boost moves.
  Both trip, so the finding stands either way, and the gap is worth one line
  rather than a repair.

The coefficient, swept over the range the literature publishes
  live = through activation_clause()'s positional slice, as shipped.
  uniform = applied to every candidate's whole term set, as a unified schema would.
    boost  in range  live pass  live <fl  unif pass  unif <fl
    0.269      True         48        11         56        25
      0.5      True         56         1         60        10
    0.695      True         59         1         60         6
      1.0      True         60         1         60         1
     1.25      True         61         1         60         1
    1.363      True         61         0         60         0
      1.5     False         61         0         60         0
  live span 48 to 61 of 67; uniform span 56 to 60.
  This is the measurement that decides what the coefficient is worth. The
  suite's pass rate responds to the coefficient only through the positional
  slice. Applied uniformly, every arm at 0.5x and above scores [60], which is
  exactly flat, and the only movement below that is the floor collapsing rather
  than the clause earning anything. So what 1.25 buys this suite is the
  asymmetry and not the clause, and tuning the coefficient on the pass rate
  would be tuning on a confound.
