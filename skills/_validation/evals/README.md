# Skill evals — with-versus-without task sets

ADR-36 (owner directive, 2026-09-29): every skill carries an eval. A
skill's claim on a builder's context window is a claim that the builder
does better work with it loaded than without it. This directory holds
the shared notes for that task; the tasks themselves live next to the
skill they measure, under `skills/<slug>/evals/`.

Status: being written by the skill seat in the run of 2026-09-30. The
harness that runs these tasks and the eval file contract they conform
to are the engineer's build in the same window.
