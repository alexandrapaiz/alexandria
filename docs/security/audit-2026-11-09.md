## 7. The MCP server

`mcp/server.py` took 53 insertions since the 2026-11-02 sweep and they are all
one change, the DSN redaction of 2026-11-01. Read closely this run because it
is the newest code on the credential path:

- `DATABASE_URL` is stripped of whitespace and surrounding quotes before libpq
  sees it, which is the fix at the step that stops the error rather than at the
  step that hides it.
- Every `psycopg.connect` exception is re-raised as a `RuntimeError` carrying
  the class and a redacted message, with `from None`, so a chained original
  cannot print the unredacted text back out through the traceback. That detail
  is correct and easy to get wrong.
- `_redact` strikes the stripped DSN, the raw environment value, and the parsed
  password of each, longest first, and refuses to redact anything shorter than
  six characters so an empty password cannot turn into a wildcard.

**One gap, low and latent rather than live.** The candidate set holds the
password as it appears in the DSN. libpq percent-decodes a URI password, so a
password containing an encoded character would reach a deeper error message in
its decoded form, which no candidate matches. Adding
`urllib.parse.unquote(password)` to the set closes it. This seat did not ship
that fix, because it cannot verify the shape of the live password without
reading it, which this charter forbids, and a redaction change that is not
tested against the shape it is for is worse than the gap. Recorded here for the
engineer with the one-line change named, and it is not urgent: it needs a
percent-encoded credential and a connection failure at the same time.

Everything else on this surface was reviewed on 2026-11-02 and has not changed:
`sql_query`'s SELECT-only enforcement through `pglast`, the per-transaction
`set local` timeout, the OAuth flow's PKCE and token lifetime, and the error
messages.
