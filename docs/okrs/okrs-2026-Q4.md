# OKRs 2026-Q4

Purpose (vision.md §0): autonomous organism, standalone knowledge
business, north star = product quality vs industry benchmarks.

First file of the OKR system. Drafted 2026-09-17, mid-Q3, on the OKR
agent's first run. Q3 has thirteen days left, so these objectives are
set for Q4 (October through December) and the September benchmark below
is recorded as the baseline the quarter is measured against. There is
no prior quarter to close, so there is no retrospective yet.

## O1 — Win the digest class on judgment and give the product a public face

The benchmark objective. The digest already has the one thing TLDR AI
and its class lack, an evidence trail, but it is invisible: one edition
sent, email only, no archive, no signup page, no deployed site. Q4 makes
the judgment advantage undeniable and puts a real surface under it.

- KR1: Thirteen consecutive Monday digests shipped by cron, 2026-W40
  through 2026-W52, with zero missed or manually triggered sends.
- KR2: The site is deployed and public by 2026-10-31 with a digest
  archive, the skill library, and a working signup, and it holds at
  least 50 email subscribers by 2026-12-31.
- KR3: Every digest item cites its evidence. A monthly audit of ten
  sampled items finds ten of ten carrying at least one claim-graph edge
  or citation-trend datum, all three monthly audits passing.

## O2 — Make the skill library a real asset, not a proof of concept

The business objective. The gold layer holds exactly one skill. It is a
good one, provenance block, twelve claims, five papers, a recorded A/B
validation, and that format is the moat, because nothing in Anthropic's
176k-star ecosystem carries an evidence trail. One skill is a specimen.
Twelve skills with that rigor is a library someone would pay $30/month
for.

- KR1: Twelve skills in gold by 2026-12-31, each with a full provenance
  block naming its claims, papers, and validation.
- KR2: prompts/skill-extract.md is shipped and the pipeline produces at
  least one draft skill per week from claim clusters from 2026-11-01
  onward.
- KR3: Twelve of twelve promoted skills carry a recorded A/B validation
  before promotion, none promoted on judgment alone.

## O3 — Close the autonomy loop from proposal to merge

The autonomy objective. Today the crons read, distill, and publish, but
every promotion and every self-improvement still waits on a human. The
reviewer panel (ADR-13) and the meta-review loop are designed and
accepted in the ledger, and neither is built. Q4 builds them.

- KR1: The reviewer panel (provenance, adversary, validator) is live
  with structured verdict rows by 2026-11-15, and the first unanimous
  autonomous merge of a promotion PR lands by 2026-12-15.
- KR2: The weekly agent runs as a scheduled task producing skill PRs by
  2026-10-15, and the meta-review loop merges its first
  self-improvement PR by 2026-12-31.
- KR3: The monthly drift audit finds zero manual substitutions in
  November and December: every publish, backfill, and promotion ran
  from a cron or action, not from the owner's terminal. Baseline: the
  institution backfill is currently a manual scratchpad script.

## Check-in 2026-09 (baseline)

First benchmark, 2026-09-17. Competitors read directly today: Elicit
(elicit.com, research-tool class), TLDR AI (tldr.tech/ai, digest
class), and Anthropic's skills ecosystem (claude.com/blog/skills plus
github.com/anthropics/skills, agent-knowledge class). Scores are
alexandria against each, 1 to 5, one sentence of evidence per score.
There is no prior month, so there is no trend yet. This row is the
trendline's origin.

### vs Elicit

- Speed to the frontier: 4. Daily arXiv ingest and a weekly frontier
  digest track the current week, while Elicit is an on-demand search
  over 125M papers with alerts, not a frontier-watching product.
- Judgment: 2. Elicit backs every AI claim with sentence-level
  citations at 2M-researcher scale, while alexandria's claim graph has
  real supports/contradicts edges but over a corpus of hundreds, with
  institution metadata still awaiting backfill.
- Actionability for a reader: 2. Elicit gives researchers interactive
  extraction tables and a systematic-review workflow with reported 80%
  time savings, while alexandria's reader gets a read-only email.
- Actionability for an agent: 4. The live MCP server (semantic_search,
  sql_query, get_digest, propose_skill) and a loadable skill beat
  Elicit, which offers agents nothing loadable.
- Product surface: 1. Elicit is a polished web app serving two million
  researchers, while alexandria's site exists only as undeployed
  Next.js code and the product ships as a single email.

### vs TLDR AI

- Speed to the frontier: 2. TLDR ships five issues a week to 1.1M
  readers, so a Tuesday result reaches their readers three days before
  alexandria's next Monday send.
- Judgment: 4. TLDR is curation with source links and no evidence
  trail, while alexandria's three sections are chosen by claim-graph
  edges and Semantic Scholar citation tracking, though only one edition
  so far proves it.
- Actionability for a reader: 3. Both are summaries with links, and
  TLDR's five-minute weekday format is easier to consume, while
  alexandria's left-behind section is a decision aid TLDR does not
  attempt.
- Actionability for an agent: 4. TLDR offers agents nothing, while
  alexandria has a live MCP server and one loadable skill, thin but
  real.
- Product surface: 2. TLDR has a public archive, referral program, and
  sponsorship engine, while alexandria has no public page at all.

### vs Anthropic skills ecosystem

- Speed to the frontier: 3. anthropics/skills grows by human PRs (55
  commits on main), while alexandria's pipeline turns fresh papers into
  skill candidates automatically but has converted exactly one.
- Judgment: 4. alexandria's skill carries claims, papers, and a
  recorded A/B validation, while Anthropic's skills carry instructions
  with no evidence trail at all.
- Actionability for a reader: 2. The Anthropic repo offers four
  browsable categories, a spec, and a template, while alexandria's
  library page is not deployed.
- Actionability for an agent: 1. Anthropic's format is the
  cross-platform standard with 176.9k stars, 20.9k forks, and a partner
  directory at agentskills.io, while alexandria has one skill written
  in that same format.
- Product surface: 1. A 176.9k-star repository plus a partner directory
  against an undeployed site.

### Baseline summary

Axis averages across the three: speed 3.0, judgment 3.3, reader
actionability 2.3, agent actionability 3.0, surface 1.3. Overall 2.6.
The instrument says the judgment engine is the strength and the product
surface is the emergency, which is what O1 and O2 exist to fix. The
harsh reading: nothing here is yet worth $10 to a stranger, because a
stranger cannot even find it.

- KR status: not applicable, first run, no prior OKRs to score.
- Drift: not applicable, first run. Noted for the October audit: the
  institution backfill runs as a manual scratchpad script, which is
  exactly the manual substitution O3 KR3 counts.
