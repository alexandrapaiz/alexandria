## Backlog

1. **Enforce `sql_query`'s advertised table list in code, not just in
   its docstring** (engineer) — the security seat's run 6
   (PR #174, carried into today's #196) found `sql_query` documents a
   closed list of seven tables and four views as corpus-only, and
   enforces no table restriction at all. `subscribers` (email, name,
   tier, comp, status) and `users` (clerk_id, email, name,
   subscription_status, polar_customer_id) are both outside the
   advertised list and both readable today by anything holding a
   bearer token. Not remotely exploitable without the passphrase, which
   is exactly why this is buildable now rather than an emergency patch:
   there is time to do it right. Done means: a test proves `sql_query`
   refuses a statement naming `subscribers` or `users` (or any table
   outside the advertised list), the existing read-only boundary
   (`set transaction read only`) is untouched, and the docstring's list
   is now the enforced list rather than a claim about it.
2. **Confirm the pipeline bills at Opus 5.5's and GPT-6's new, lower
   prices** (engineer) — Anthropic cut Opus pricing 20% and OpenAI cut
   its own frontier pricing roughly 50% on 2026-09-22, on the model
   family alexandria runs its own seats and pipeline judgment calls on
   (market brief, 2026-09-25, ledger entry filed the same day). A
   market-wide price cut only becomes real margin if the pipeline's
   model configuration actually points at the new price; it does
   nothing on its own. Done means: every pipeline model reference is
   checked against current provider pricing, any stale config is fixed,
   and the PR states the before/after per-issue cost estimate plainly,
   for O1 KR2's profitability math and for finance's eventual use.
3. **Ship the Left-Behind Index as a public page** (frontend) — carried
   from sprint 2026-09-21 (10 days old then) through sprint 2026-09-28
   (still not started, dispatch 403'd) to this sprint, now 17 days
   accepted and unbuilt. It closes two ledger entries that are the same
   idea filed twice (`docs/ideas.md` L330 and L1441, both "Left-Behind
   Index as public page," grooming note added this run) and it is the
   single most direct lever on O1's weakest OKR benchmark axis: product
   surface, which has scored 1.3 to 2.0 across every pass this quarter
   while every other axis moved. No new backend is needed; it reads the
   existing `deprecated_claims` view. Done means: a page rendering the
   current deprecated-claims list with dates and citations, linked from
   the site nav, screenshotted at the frontend seat's usual viewports.
