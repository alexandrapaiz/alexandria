## Findings that matter

1. **An academic paper now measures, rather than just argues, why a
   flat public skill library breaks down at scale, and the number is
   severe.** "Lost in Implicit Routing" (arXiv 2610.18522, posted
   2026-10-13) holds a fixed set of tasks and golden skills constant
   (the same set SkillsBench already uses, tracked in this doc since
   2026-09-30) and adds irrelevant skills to the library an agent must
   choose from. At 1,000 irrelevant skills added, loaded-skill recall
   for the correct skill falls from 73.6% to 27.4%, and the rate at
   which the agent loads no skill at all rises from 9.3% to 51.6%.
   Explicit pre-selection from the same library holds recall at 73.9%.
   [arXiv 2610.18522](https://arxiv.org/abs/2610.18522)
   **So what:** this is the fifth independent measurement of the
   skills-trust gap this doc has tracked since 2026-09-18, and the
   first that argues a mechanism instead of adding to a count of
   unsafe, mediocre, or unused skills. It is also the strongest
   evidence yet behind a ledger proposal that has sat unactioned for
   four weeks ("Scoped skill delivery by default," docs/ideas.md,
   2026-09-18), escalated this run with this paper's numbers attached.

2. **Practitioners are already hand-building fixes for the same
   problem, not waiting for a vendor.** The Cursor community forum has
   an open thread of users reporting skills that are discovered
   (visible in Settings and the slash menu) but never injected into the
   agent's actual system prompt.
   [forum.cursor.com/t/cursor-agent-skills-in-agents-skills](https://forum.cursor.com/t/cursor-agent-skills-in-agents-skills/161142)
   Separately, at least three small discovery or routing tools
   (AgentSkill.club, Agent-i-Kit, a TanStack registry that auto-indexes
   npm-published skills) have appeared around the same gap this run
   found, each solving discovery alone with no evidence attached to a
   skill's claims.
   **So what:** nobody observed in this market sells the fixed version
   of this problem. The gap finding below names this plainly.

3. **Consensus's contested pricing has now held at $20/month for two
   consecutive checks.** The primary pricing page is still unreachable
   directly (sixth attempt, same client-side-render block tracked since
   2026-09-30), but costbench.com's reading has been $20/month on both
   this run and the 2026-10-05 re-check, after the single contested
   $15/month reading on 2026-10-02.
   [costbench.com](https://costbench.com/software/ai-research-tools/consensus/)
   **So what:** no change to alexandria's $20/month. This looks like a
   figure settling rather than a source that keeps swinging, though
   this doc still treats one aggregator, read twice, as a pattern and
   not a second primary source.

4. **A fourth entrant joined the orchestration-pattern thread this doc
   has tracked since 2026-09-18, this time addressing a failure mode
   the first three did not.** RRSI (arXiv 2609.24972), from Google
   Cloud AI Research with academic co-authors, regularizes the loop
   that repeatedly edits an agent's own prompts and tools, reporting
   gains of up to 14.1 points in-distribution and 4.7 out-of-distribution
   over unregularized harness evolution, at roughly 30% fewer policy
   tokens, specifically to stop training-task gains from evaporating on
   held-out benchmarks. [arXiv 2609.24972](https://arxiv.org/abs/2609.24972)
   **So what:** named for the research seat's signal read, same routing
   as the rest of this thread (Strands Harness, the CMU message-passing
   paper, OrchBench). Not new this week (posted around 2026-09-21,
   secondary sources disagree by two days), new to
   this doc. No pricing or positioning signal.

## The gap

The clearest unmet need this week is not about trust in a skill's
content, which this doc has argued for a month. It is about whether an
agent can find the right skill at all once the library is large enough
to matter. A controlled study now puts a number on exactly how badly
naive delivery fails at the scale alexandria's own paid tier is built
to reach (finding 1), and practitioners are already patching around it
by hand with small, uncoordinated tools (finding 2) rather than buying
a solved version from anyone. Nobody observed in this market sells
curated, evidence-backed, *scoped* delivery as one product. That is
exactly the gap the still-open "Scoped skill delivery by default"
proposal names, and exactly why this run escalates it rather than
filing something new.

## Report for the owner

The biggest market fact this week is not a competitor move. It is a
controlled academic measurement of the exact problem alexandria's
skill library is built to solve: once a public skill library passes a
few hundred entries, an agent's own ability to find the right skill
collapses, recall falling from 73.6% to 27.4% at 1,000 irrelevant
skills added, even though the right skill never left the list.
Practitioners are already hand-patching this with small discovery
tools rather than buying a fix. Nothing this week argues for a change
to $20/month, Consensus's price held steady for a second check and
nothing else moved the ladder. What is worth your attention outside
pricing is the ledger: a proposal filed the first week this charter
existed, 2026-09-18, has sat untouched for a month, and it now has a
number behind it that the original HN-commenter trigger did not.
