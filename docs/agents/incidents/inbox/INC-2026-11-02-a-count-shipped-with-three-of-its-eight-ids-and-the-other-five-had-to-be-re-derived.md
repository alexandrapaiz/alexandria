## INC-2026-11-02-a-count-shipped-with-three-of-its-eight-ids-and-the-other-five-had-to-be-re-derived - an audit's own figure had no receipt, in the row below the one accusing the estate of the same thing (2026-11-02, research seat, message wake, PR #691)

**What happened.** On 2026-11-02 this seat audited all 102 `without_skill`
predictions in the nine eval suites and published a table of six rows. One row
read "reason from this repository's own history rather than from a subject: 8".
The prose named three of the eight. The other five were nowhere in the note, in
the queue line that carried the answer, or in the message that routed it.

The skill seat labelled the same 102 tasks the next hour, counted three, and
asked this seat to name its five or concede them. Answering took a second pass
over the same files, because the first pass left no record a second reader could
check. The reconstruction landed on exactly eight ids, which corroborates the
original count, and that is luck rather than method: eight was recoverable only
because the property is lexically visible in the text. The adjacent row of the
same table, "cite an observed run of the unaided arm: 1", was recoverable
because the note happened to name its one id.

**Why it is a repeat and not a first.** The whole audit it belongs to was an
argument that a figure without an independent record is the author's model of
the thing rather than a measurement of it. The defect is in the row below that
argument, written by the seat making it, in the same document, on the same day.
The register already holds this class under other subjects:
`INC-2026-11-01-a-count-read-off-the-re-fire-record-mid-drain-is-a-progress-bar-not-a-measurement`
is the same shape with a different instrument, and
`INC-2026-11-02-the-four-numbers-that-corrected-the-headline-are-labelled-frontier-and-none-of-them-is`
is the other half of today's pair, where the quantity was checkable and the word
in front of it was not. Here the quantity was the uncheckable part.

**What it cost and what it did not.** No wrong number reached anything. What it
cost was one seat-pair exchange and two runs of re-derivation, and what it
nearly cost is larger: a count defended from memory would have been defended
against the wrong four, because four of this seat's eight were in fact wrong and
one of the skill seat's four counter-examples was never in the eight at all.
Both sides were arguing about a set neither could enumerate.

**The remedy, and it is this seat's own.** A count over a corpus the seat can
read is a script or it is an anecdote. This run wrote
`docs/research/notes/2026-11-02-prediction-basis.py`, which prints every id in
every bucket and runs in under a second with no corpus, and the answer to the
skill seat cites it rather than a reading. The general rule, worth more than the
script: where a brief or an audit reports `N of M`, the ids go in the artifact
or the artifact says why they cannot. A bare `N of M` in a register is the
instrument's own `without_skill` field, which is exactly what this seat spent
that run measuring.
