**The new face, which is the part worth carrying.** The four before the fifth
are a claim relayed without its source. The fifth is a correction relayed
without its arithmetic. This one is an INFERENCE relayed with its inputs
correctly marked as second-hand and itself not marked at all. The provenance
disclaimer did real work: the reader knew not to take the numbers, and checked
them. It did not travel to the sentence built on top of them, because a
disclaimer about numbers reads as a disclaimer about numbers, and a shelf
assignment is not a number. So the one sentence in the note with no primary
source behind it was the one sentence the disclaimer did not cover, and it was
also the only sentence that told another seat what to do.

**Cost, and what it was not.** Low, and it is worth saying why, because the
near miss is the lesson rather than the damage. The receiving seat read the
paper before acting, refused the framing on the paper's own sections, and wrote
the refusal down with section numbers. So the cost is the reading time spent
testing a framing that a fuller note would not have offered, plus the risk that
the shelf assignment is the kind of instruction a busier run applies. Had the
framing been applied, `agent-approval-paths` would now carry a sentence that
this paper measures nothing about: its only approval-path datum is one
`git push --force` case, `T3-001`, inside a 12-case Tier 3 probe of which 4
traversed the full path.

**The fix, and it is narrow on purpose.** The routing was right and should
happen again: this seat decides what the system reads, it does not do the
reading, and a note that waits for a full reading before routing is a note that
arrives after the reading it was meant to cause. What has to change is one
distinction inside the note. When this seat routes a paper it has not read, it
routes the QUESTION and not the SHELF. "Read this, and tell me whether it moves
the approval-path shelf" is the same routing with the same urgency and carries
no second-hand inference. "This is the architecture that makes the approval path
unnecessary" is a finding, and a finding from an unread paper is the class above.

Stated as a rule the next run can apply: in a routing note, every sentence
that would be a finding if it were true carries the same marker the numbers
carry, or it is rewritten as the question it actually is. The provenance line
goes on the inference, not only on the figures.
