## INC-2026-11-09-the-relayed-claim-class-has-a-measured-mechanism-and-it-runs-one-way - another face of the relayed-claim class, and the first with a mechanism measured across four summaries instead of one instance (2026-11-09, research seat, message run on skill's v7 done)

**Written because the standing rule binds.** The class is recorded at least
seven times already and every entry records one instance:
`INC-2026-10-26-the-relayed-citation-class-repeats-inside-the-queue-line-written-to-catch-it`,
`INC-2026-10-27-a-queue-line-named-a-capability-benchmark-as-the-source-of-a-security-table`,
`INC-2026-10-27-a-queue-lines-stated-reason-was-carried-through-an-amendment-and-had-been-false-since-the-day-it-was-written`,
`INC-2026-11-02-a-shelf-assignment-was-routed-from-a-paper-this-seat-had-not-read-and-the-reading-reversed-it`
(which names itself the sixth face),
`INC-2026-11-02-a-queue-line-asserted-its-own-premise-and-the-premise-went-unchecked-for-thirty-three-days`,
`INC-2026-11-01-the-queue-line-asserted-a-caveat-the-paper-does-not-carry`
and
`INC-2026-11-09-the-provenance-label-was-attached-to-the-abstract-half-and-the-wrong-half-was-the-arithmetic`.
No face number is allocated here, per the numbering rule at the top of the
register: this entry is written on a branch and cannot see the highest face
that exists.

**What happened.** The skill seat asked, on PR #919, whether a citing paper's
summary of a rival mechanism systematically drops the fields its own mechanism
lacks, having found one measured instance: `2609.38983` section VIII-A
summarises `2609.21081`'s six-field canonical approval record as five fields
and drops the digest over the rendered descriptor, which its own seven-field
credential has no counterpart for.

This run read all nine papers of that cluster in full and measured every
ordered pair in which one paper describes another's mechanism. Four passages
enumerate three or more of the summarised paper's own components and so can be
said to drop anything. Across those four, **ten of ten components with no
counterpart in the summariser's own design were dropped**, and the result is
not explained by importance in the summarised paper: `2609.38983` and
`2609.18411` both summarise `2606.02668` and the halves they keep are
disjoint, each one matching what its author built. Details and the per-case
tables are in `docs/research/notes/2026-11-09-ceiling-null.md`.

**Why it keeps happening.** Every prior entry records an instance and none
records a mechanism, so each run rediscovers the class from a new angle and
files it as new. The mechanism is that a summary is written in the
summariser's own design vocabulary, so a component the summariser has no slot
for has nowhere to land. That makes the hazard one-directional and therefore
predictable rather than a matter of care: it is not that related-work sections
are sloppy, it is that they are lower bounds, and the parts they omit are
exactly the parts a prescription built on them will be blind to.

**The cost here was already paid.** The corpus knew `2609.21081` only through
`2609.38983` section VIII-A for weeks. The dropped field was the digest over
the complete descriptor shown to the human, and `agent-approval-paths` shipped
a prescription with a ceiling and no precondition as a direct result, which the
skill seat corrected across v5 to v7 today.

**Not fixed in this run, and the reason is recorded rather than worked
around.** The rule this supports is one sentence, and its two homes are
`prompts/skill-extract.md`, which is image-baked and whose deployed sha is a
database read this seat cannot perform, and the reading queue's own header.
The research charter forbids spending a proposal on an image-baked file whose
running image cannot be shown to be current, so the rule is routed to the
skill seat on the bus and named in PR #926 for the PM, not merged into a
charter by the seat that measured it.

**The rule, in the form the measurement supports.** A related-work summary is
admissible as evidence that a mechanism exists and is never admissible as
evidence of what the mechanism contains. A reading-queue line for a
cited-but-unread paper should name whose description it rests on, so the next
reader knows it is reading a lower bound.
