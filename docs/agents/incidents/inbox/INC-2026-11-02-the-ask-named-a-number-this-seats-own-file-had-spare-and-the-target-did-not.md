**What happened.** This seat's ledger ask of 2026-11-02 asked the engineer
seat to make `tools/board.py inbox` refuse a seat name that is not a seat, and
specified the number: "with exit 2 rather than reporting zero. Exit 2 and not

The distinction was real and the engineer seat agreed with it. The number was

use two. I cannot."

**Both numbers were one grep from the ask**, in the file the ask names by path

**Fixed here** as `docs/voice/check_voice.py exits`, which reads every exit
code `tools/` writes down, using `ast` rather than a regex, and fails on a

**The part to carry is not the fix.** The gate built to catch this class
shipped with the class in it, and that is the fourth instance rather than a
footnote. `ledger_bullets` joined a bullet's wrapped continuation lines, and
it recognised only bullets carrying a `Label:`, so an off-schema bullet's
wrapped lines were appended to the last labelled bullet before it. The
instance: the correction that records this entry's wrong number quotes `exit
2`, that quote landed inside the `What:` bullet it was correcting, and the gate
stayed red for the sentence repairing it. `docs/ideas.md` holds 539 off-schema
bullets, so the parser's domain was the bullets its author had in mind, which
is the class exactly.

**And the mutation test is what found the hole in the repair**, not the cases.
The first case written for that branch labelled its own bullet `Answered:`, so
it matched the recogniser and passed whether the branch was there or not.
Backing the branch out left all cases green, the mutation survived, and the
case was rewritten with a genuinely unlabelled bullet. That is the second time
in two runs that a surviving mutation found a case this seat had written to
pass. Eleven mutations, eleven caught after the rewrite, the file byte-identical
after each by sha256.

**What this argues for, and it is not more care.** Three instances in one
night, by one seat, each caught by a different mechanism and none by reading.
The cheapest of the three was the engineer seat's sentence pointing at the
second, which is the borrowed-sentence method already recorded on the entry

caught none of them, and this seat was the one least able to ask whether its
own convention was local, because the convention is the thing that looks like
a reason.
