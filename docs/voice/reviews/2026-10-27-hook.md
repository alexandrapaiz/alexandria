## The single biggest weakness, and it is not a line in the issue

Every verdict below is a verdict on `prompts/digest.md` as it stood at
`9b6410ea`, 2026-10-14T20:08Z. That is the version of the generator the press

the oldest of them has been waiting twelve days.

So the issue in front of a reader was written by a machine that has never seen
the fixes for the failures a reader can still find in it. The three list-shaped
procedures run 51 diagnosed are still comma-runs on the live page, and the
patch that would render them as lists merged on 2026-10-26 as `2c6ce635`. The

This is not a complaint about the engineer's queue, which is blocked on a
disabled Modal workspace and is already written down in
`docs/agents/engineer-run-note-2026-10-25-message.md`. It is a statement about
what a grade is worth. Three consecutive runs have graded one page and patched
the generator, and the artifact cannot move until somebody deploys, so the
editor's loop is open at the far end and the grade is the only half of it that
runs.

## The instrument stopped answering, and the cause is this seat's own output

Run 51 read a number off the deploy surface: `prompts/digest.md` 10.4 days
behind with 31 undeployed commits. The same command today answers that the
question cannot be asked.

```
python3 tools/delivery_health.py --surface deploy --no-notify
  ... and the deploy cannot be compared from here for: weekly
      (the drift cannot be dated from this checkout)
```

Nothing about the deploy changed between those two readings. The row the
surface reads is unchanged since 2026-10-19 and the clone is fully unshallowed.
What changed is the number of commits that touch the app's files, and this seat
is what moves it.

`tools/delivery_health.py` recovers the deployed commit by replaying the
image's content digest over history until a commit reproduces it, and it walks
`DEPLOY_HISTORY_LIMIT` commits, which is 40. The `weekly` image's file list
includes `prompts/digest.md`, the one file this seat edits on every run. The
deployed commit now sits at walk position 43.

```
undeployed_commits(root, 'weekly', '2e313065f5c7', limit=40)
  the running digest 2e313065f5c7 matches none of the last 40 commits to
  touch this app's files, so the deploy was built from code that is not in
  this history
undeployed_commits(root, 'weekly', '2e313065f5c7', limit=60)
  deployed_commit f16e2775  2026-10-15T17:40:37+00:00  undeployed 42
```

Three commits of margin is the whole difference between a number and a refusal.
Twenty-four of the forty-two undeployed commits touch `prompts/digest.md`, so
the surface loses the ability to date the press roughly in proportion to how
hard this seat works on it. An editor who patches nothing keeps the
instrument. An editor who patches daily blinds it inside a fortnight.

The sentence it prints instead is false, and that is the part worth filing
rather than the limit. `f16e2775` is nine days old, it is an ancestor of
`origin/main`, and it is sitting in the checkout the surface read. "The deploy
was built from code that is not in this history" is the one reading a seat
cannot act on, because it describes a state that would mean somebody deployed
from an unpushed tree. The ledger entry this run adds asks for the window to
grow and for the refusal to say how far it looked.

It is also a repeat and it is filed as one.
`INC-2026-10-24-the-deepening-fetch-landed-the-history-and-called-it-a-failure`
is the same shape: the history is in the checkout and the surface says
`unknown` over the top of it. That entry fixed the case where the fetch
succeeded and exited non-zero. This is the case where the fetch succeeded and
the walk was too short.

## Why there is no prompt diff in this run

Three failures above are real and none of them is a wording this seat has not
already written.

Law 1's two semicolons are held by the generator's own count and by the
pre-send gate, and run 54 refused a fourth wording of it on 2026-10-26.
Law 8's link form is in the ledger, escalated by run 51.
Law 14's two missing devices and law 3's three procedure frames are one patch,
and that patch merged yesterday as `2c6ce635`.

Law 12a is the one failure with no patch in the queue, and it is also the one
this run deliberately leaves alone. The generator's first-use rule exists, the
issue broke it in eleven places, and the version of the generator that wrote
those eleven places is twelve days old. A fifth wording of a rule whose fourth
wording has not yet reached the press is the exact move the structure-watch
step was written to refuse, and the evidence that it would be waste is
`shapes 1`: the shape patch has been written three times and the page has read
one shape for three issues, because none of the three reached the machine.

So the generator's next measurable move belongs to a deploy. What this run
ships instead is the instrument that makes the next run's first question
answerable in one command rather than in forty minutes of replaying digests
over history.
