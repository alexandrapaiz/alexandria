## If the Obsolescence Report runs

It replaces teaser 3 entirely. Do not announce the report in advance. A
document whose whole effect is that nobody expected it loses that effect to a
countdown, and there is no version of "wait until Tuesday for our errata" that
reads as anything but a stunt.

## Standing rules for all three

- The ask is the waitlist and the waitlist only, in the page's own promise. No
  invented deadline, no founding-member price, no early-access tier that does
  not exist.
- No paper count with the verb "read" attached unless it is the full-read count
  beside the arriving count.
- The repository link is the receipt in every post, because it is the one thing
  a stranger can check in a single click.
- Plain ASCII throughout.
