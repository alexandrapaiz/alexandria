# Results — what actually happened

Populated by the sales agent once the owner reports results or public
numbers exist (subscriber counts, referral traffic, post performance).
Empty on this first run by construction — nothing has been sent yet.

Format for future entries, one per dated send:

```
## YYYY-MM-DD — [channel/asset]
- What was sent: [link to the docs/sales/ file used]
- Result: [real number the owner reported, or "not yet measured"]
- Steers next campaign: [one line, only if there's a real lesson]
```

No entry is invented or estimated here — this file only ever contains
numbers the owner actually reported or that are independently public
(e.g., a real HN point count, a real post's public like count).
