# alexandria digest — 2026‑W37  

Long‑horizon training is getting a boost from richer feedback signals.  The **Feedback‑Enriched Environments (FEEs)** introduced this week consistently raise performance on tough benchmarks, and the community is already noting that stable training hinges on keeping feedback consistent within groups.  At the same time, production‑grade post‑training stacks are maturing: **Miles** shows how to run asynchronous RL on trillion‑parameter models, while **NeoHorse** demonstrates routing‑harnesses that steer capability demand and continual improvement.  Both currents point to a shift from isolated fine‑tuning toward integrated pipelines that embed evaluation feedback directly into the training loop.

## Trailblazing  

**Feedback‑Enriched Environments lift long‑horizon agent performance.**  
Why it matters: adopt FEEs to get higher success rates on sparse‑reward tasks without extra inference tricks.  
*Environments as Scaffold: Enriching Feedback to Bootstrap Self‑Evolving Agents in Long‑Horizon Tasks* — [link](https://arxiv.org/abs/2609.08404)  

**Consistent intra‑group feedback is a stability boundary for FEEs.**  
Why it matters: design your feedback pipelines so that signals stay uniform across a batch; otherwise training diverges.  
*Environments as Scaffold: Enriching Feedback to Bootstrap Self‑Evolving Agents in Long‑Horizon Tasks* — [link](https://arxiv.org/abs/2609.08404)

*Miles v0.1: Production‑Level Post‑Training* — [link](https://arxiv.org/abs/2609.08368)

## Gaining traction  

- **Puffin‑World** unifies physics, geometry, and appearance as native world states, removing the need for external offline modules. Growing support (3 + edges) signals that native 3‑D world representations are becoming a standard building block.  
- **Compile‑by‑Training** turns natural‑language specs into reusable neural functions that run without teacher models at inference. Three independent groups now cite it, indicating a move toward compile‑time neural code generation.  
- **Inference‑time context management** (limited tool set, fixed judge) yields larger gains than most system tweaks across benchmarks. Consensus (3 + edges) suggests you should prioritize context handling in your agents.  
- **One‑shot on‑policy distillation (OPD)** trained on a single query recovers most of the performance of full‑data OPD across tasks. Two separate studies now back this, encouraging lightweight distillation pipelines.  
- **Rationale‑only supervision** reduces false refusals while keeping overall safety intact. Two papers now support this, making it a viable safety‑tuning shortcut.  
- **Random Attention** matches top KV‑cache evictors while delivering 32‑43 % higher throughput in vLLM deployments. Two confirmations point to it as a practical cache‑eviction strategy.  
- **RISE** combines outcome‑based RLVR rewards with on‑policy distillation, forming a complementary loop that grounds extrapolation and refines token‑level decisions. Two citations endorse this loop design.  
- **WorldReward** decomposes paired videos into action‑aligned chunks, votes on chunk‑level decisions, and aggregates to video‑level preferences. Two independent supports highlight its modular evaluation approach.  
- **Boilerplate refusal statements** cause models to over‑rely on superficial cues, harming discrimination between harmful and benign queries. Two studies now warn against this pattern.  
- **Using 16 semantically diverse queries in OPD** reaches 98.9 % state coverage and matches full‑data validation accuracy. Two confirmations make this a practical coverage shortcut.

## Left behind  

**Contradicted**  
- The claim that Claude Opus 5 under Claude Code passes only 23.9 % of simulations is overturned by an expert reference implementation achieving 82.2 % success. Expect higher baselines in future benchmarks.  
- The idea that a single ReAct agent without sub‑agents can solve the hardest rollouts is refuted by a shared executable‑skill interface that combines high‑level selection, bounded low‑level VLA execution, and post‑action verification. Build modular skill interfaces instead of monolithic agents.  
- The earlier assertion that the expert reference implementation reaches 82.2 % success is contradicted on memory‑dependent RMBench tasks, where the same approach drops to 12.5 % average success. Memory‑intensive workloads still need dedicated solutions.

- *WorldReward: Reward Modeling for Camera‑Conditioned World Models* (joint action‑and‑visual quality evaluation) is giving way to the newer claim that **WorldReward decomposes videos into action‑aligned chunks and aggregates chunk‑level votes**.
