# alexandria digest — 2026‑W37  

This week the conversation turned around two ideas. First, giving agents richer signals from their surroundings—what the papers call feedback‑enriched environments—appears to make long‑horizon learning both faster and more stable. The claim is backed by large‑scale experiments on multiple model families and reinforcement‑learning algorithms. Second, the community is converging on modular post‑training pipelines that treat the training loop as a set of interchangeable components, from rollout engines to routing‑based data selection. Both currents promise to reduce the engineering friction that currently dominates agent development.

## Trailblazing  

**Feedback‑Enriched Environments improve long‑horizon agent performance.**  
The authors introduce feedback‑enriched environments (FEEs), which augment observations with additional signals that guide learning. Experiments with Qwen‑13 model variants and three reinforcement‑learning algorithms (GRPO, GSPO, DAPO) show consistent gains on the SciWorld and BFCL benchmarks compared with standard settings. The study also finds that when feedback is consistent within a group, training remains stable, while inconsistent signals cause divergence. Moreover, agents trained in FEEs explore broader state spaces and retain performance even when the enrichment is removed at test time, indicating that the guidance is internalized into policy weights. Builders should consider adding structured feedback channels to their environments to accelerate learning on sparse‑reward tasks.  
*Environments as Scaffold: Enriching Feedback to Bootstrap Self‑Evolving Agents in Long‑Horizon Tasks* — [link](https://arxiv.org/abs/2609.08404).

**Miles delivers a production‑grade post‑training stack for large‑scale RL.**  
Miles v0.1 is a modular system that runs end‑to‑end reinforcement‑learning loops on frontier models. Its rollout engines are built on SGLang, and a case study reports a median step time of 263 seconds for a 744 B GLM‑15.2 model using 64 NVIDIA GB300 GPUs, demonstrating efficient asynchronous execution. The system supports both NVIDIA Megatron‑LM and PyTorch FSDP backends and offers three weight‑synchronization transports to match different deployment topologies. The authors emphasize verified, clean, and customizable components, making the stack ready for production use. Teams can adopt Miles to reduce engineering overhead and achieve comparable throughput on massive models.  
*Miles v0.1: Production‑Level Post‑Training* — [link](https://arxiv.org/abs/2609.08368).

**NeoHorse uses a routing harness to turn evaluation feedback into training data.**  
The paper presents a routing‑harness that records user‑turn interactions, predicts capability demand, and selects service tiers for each turn. Routing signals organize supervised fine‑tuning into a three‑stage curriculum and guide on‑policy distillation, where a teacher model supervises student‑generated responses. This closed loop converts evaluation results into the next training mixture, a process the authors call capability‑guided allocation. On eleven benchmarks, the 4 B model’s macro‑average score rises from 58.94 to 64.87, and the 9 B model improves from 65.60 to 69.04, narrowing the gap to larger base models. Practitioners can adopt the routing harness to create self‑improving pipelines that continuously adapt to new capabilities.  
*NeoHorse‑1: Towards Recursive Self‑Improvement via Agentic Post‑Training with Routing Harness* — [link](https://arxiv.org/abs/2609.08183).

**MaxKernel’s sub‑agent pool automates TPU kernel generation at expert level.**  
MaxKernel assembles a shared pool of specialized sub‑agents for planning, implementation, self‑debugging, testing, and hardware profiling. These sub‑agents are reused across three generation paradigms: human‑in‑the‑loop, fully autonomous, and graph‑based autonomous search. The system’s autonomous metric‑and‑trace driven loop delivers notable speedups on the JaxBench benchmark, and the graph‑based search further improves performance on large‑scale workloads. Evaluation on 50 diverse tasks shows that the generated kernels match the performance of hand‑tuned expert baselines. Developers of hardware‑aware agents can leverage this architecture to offload low‑level optimization to coordinated sub‑agents.  
*MaxKernel: Agentic Kernel Generation for TPUs* — [link](https://arxiv.org/abs/2609.04523).

**Gander separates fast interaction from deep reasoning with a Cerebellum‑Brain framework.**  
The Omni Interaction Agent introduces a streaming Thinker‑Talker architecture that flattens inputs and outputs into an ordered token stream at the chunk level, enabling low‑latency duplex communication. Behind this stream sits a Cerebellum‑Brain collaboration: the Cerebellum handles real‑time interaction, while the Brain performs complex reasoning and tool‑calling. Continuous orchestration between the two components allows the system to process video, speech, and text inputs simultaneously. This design offers a blueprint for building agents that need both immediate responsiveness and high‑level problem solving.  
*Omni Interaction Agent Technical Report* — [link](https://arxiv.org/abs/2609.08977).

## Gaining traction  

Puffin‑World’s unified 3D world state representation eliminates the need for external offline modules, and three independent papers now cite it as evidence of its utility.  

Compile‑by‑training turns natural‑language specifications into reusable neural functions, and three separate works support its effectiveness.  

Inference‑time context management—limiting tool sets, context length, and using a fixed judge—shows larger gains than most system changes, with three supporting claims.  

One‑shot on‑policy distillation improves performance for hundreds of steps and recovers most of full‑data gains, backed by two independent studies.  

Training on rationale‑only supervision reduces false refusals while keeping overall safety, confirmed by two papers.  

Random Attention’s uniform cache eviction matches the strongest prior methods while delivering 32 %–43 % higher throughput, with two supporting citations.  

RISE’s combination of outcome‑based rewards and on‑policy distillation creates a complementary loop, cited by two works.  

WorldReward’s chunk‑level voting aggregates visual evidence to produce reliable video‑level preferences, supported by two papers.  

Boilerplate refusal statements cause models to rely on superficial cues, impairing harmful‑benign discrimination, with two independent confirmations.  

Using 16 semantically diverse queries in on‑policy distillation reaches 98.9 % state coverage and matches validation accuracy of full‑data training, also supported by two studies.  

## Left behind  

**Contradicted**  
The claim that Claude Opus 5 under Claude Code passes only 23.9 % of evaluation simulations is overturned by an expert reference implementation achieving 82.2 % success; the older benchmark result should no longer be used as a baseline.  

The claim that a single ReAct agent without sub‑agents can solve the hardest rollouts is contradicted by evidence that a shared executable‑skill interface combining high‑level selection, low‑level VLA execution, and post‑action verification yields superior performance; single‑agent designs should be retired.  

The claim that the expert reference implementation reaches 82.2 % success is itself contradicted on memory‑intensive RMBench tasks, where the same approach attains only 12.5 % average success; reliance on that implementation for memory‑heavy workloads is unsafe.
