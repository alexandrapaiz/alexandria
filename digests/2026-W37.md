# alexandria digest — 2026‑W37  

Long‑horizon reinforcement learning is finally getting a boost from two complementary ideas.  First, **Feedback‑Enriched Environments (FEEs)** reshape the reward signal so agents can explore more proactively and learn more stably.  Second, **modular post‑training pipelines** such as Miles and NeoHorse are proving that large‑scale RL can be run reliably on frontier models.  Both currents aim to tame the instability and compute cost that have limited agentic systems, and the claims below show early, reproducible wins.

## Trailblazing  

**Feedback‑Enriched Environments consistently improve performance on long‑horizon tasks.**  
Why it matters: Use FEEs as a scaffold when training self‑evolving agents to get higher scores on benchmarks like SciWorld and BFCL.  
*Environments as Scaffold: Enriching Feedback to Bootstrap Self‑Evolving Agents in Long‑Horizon Tasks* — [link](https://arxiv.org/abs/2609.08404)

**Training with FEEs stabilizes agent dynamics by cutting entropy volatility.**  
Why it matters: Expect smoother loss curves and fewer catastrophic drops, which simplifies hyper‑parameter tuning.  
*Environments as Scaffold: Enriching Feedback to Bootstrap Self‑Evolving Agents in Long‑Horizon Tasks* — [link](https://arxiv.org/abs/2609.08404)

**FEEs enable proactive state‑space exploration in difficult tasks.**

*Environments as Scaffold: Enriching Feedback to Bootstrap Self‑Evolving Agents in Long‑Horizon Tasks* — [link](https://arxiv.org/abs/2609.08404)

**Miles v0.1 reaches a median step time of 263 seconds for fully asynchronous RL on a 744B model using 64 GPUs.**  
Why it matters: The system shows that production‑grade, asynchronous RL is feasible at frontier scale, guiding infrastructure design.  
*Miles v0.1: Production‑Level Post‑Training* — [link](https://arxiv.org/abs/2609.08368)

**Miles v0.1 supports both Megatron‑LM and PyTorch FSDP backends with three weight‑synchronization transports.**  
Why it matters: Choose the backend that matches your hardware topology without rewriting training code.

**NeoHorse routing‑harness raises macro‑average performance on eleven benchmarks (4B model: 58.94 → 64.87, 9B model: 65.60 → 69.04).**

*NeoHorse‑1: Towards Recursive Self‑Improvement via Agentic Post‑Training with Routing Harness* — [link](https://arxiv.org/abs/2609.08183)

**MaxKernel’s multi‑agent system matches expert hand‑tuned TPU kernels on JaxBench and real‑world workloads.**

## Left behind  

- The claim that “Claude Opus 5 under Claude Code passes only 23.9 % of 53 simulations” is contradicted by an expert reference implementation achieving 82.2 % success.  Builders should no longer treat Claude Opus 5 as a performance ceiling.  
- The claim that “a single ReAct agent without sub‑agents can solve the hardest rollouts” is contradicted by evidence that a shared executable‑skill interface with verification dramatically improves performance.  Relying on monolithic ReAct agents is now discouraged.  
- The claim that “the expert reference implementation achieves 82.2 % success” is itself contradicted on memory‑intensive RMBench tasks, where the same approach drops to 12.5 % success.  Expect sharp drops on tasks requiring extensive memory handling.
