# alexandria digest — 2026‑W37  

This week the most compelling thread is the convergence of **autonomous loop engineering** with **multi‑agent coordination**.  Papers such as *MaxKernel* and *Iris* demonstrate that tightly coupled sub‑agents can drive a self‑optimising search loop without human oversight, while *DRACO* and *RISE* show how dynamic credit assignment and recursive self‑distillation tighten that loop further.  A parallel current is the push for **efficiency through structured sparsity**, exemplified by layer‑dropout work that promises sizable FLOP reductions without sacrificing accuracy.  Both currents point toward agents that are not only more capable but also cheaper to train and run.

## Trailblazing  

**Graph‑Based Autonomous Search lets an Auto agent scale kernel generation to the full TPU design space.**  
By delegating exploration to a graph‑structured search, MaxKernel can automatically discover high‑performance kernels, a capability directly reusable for any hardware‑aware agent.  *MaxKernel: Agentic Kernel Generation for TPUs* – [link](https://arxiv.org/abs/2609.04523)  

**A shared pool of specialised sub‑agents enables both human‑in‑the‑loop and fully autonomous kernel generation.**  
The architecture separates planning, implementation, debugging, testing and profiling, making it straightforward to swap in or out human guidance.  *MaxKernel: Agentic Kernel Generation for TPUs* – [link](https://arxiv.org/abs/2609.04523)  

**Iris‑mini (35B) and Iris‑pro (397B) set new open‑source benchmarks on BrowseComp, BrowseComp‑ZH, DeepSearchQA and HLE.**  
These results prove that large‑scale search agents can be built from open models, lowering the barrier for reproducible agent research.  *Iris: Climbing to the Search Frontier* – [link](https://arxiv.org/abs/2609.04304)  

**Iris’s SFT‑RL climbing loop alternates supervised fine‑tuning with live‑search reinforcement, interrupting over‑long rollouts at the request level.**  
The procedure yields stable policy improvement while keeping compute bounded, a pattern applicable to any RL‑driven agentic system.  *Iris: Climbing to the Search Frontier* – [link](https://arxiv.org/abs/2609.04304)  

**Inference‑time context management (fixed tool set, limited context length, static judge) delivers larger gains than most system changes.**  
This finding suggests that careful runtime constraints can be more impactful than architectural tweaks alone.  *Iris: Climbing to the Search Frontier* – [link](https://arxiv.org/abs/2609.04304)  

**A single ReAct agent, without sub‑agents or test‑time verification, can solve the hardest rollouts when combined with the above training and context tricks.**  
It shows that sophisticated multi‑step reasoning can emerge from a streamlined design, informing when to invest in sub‑agent complexity.  *Iris: Climbing to the Search Frontier* – [link](https://arxiv.org/abs/2609.04304)
