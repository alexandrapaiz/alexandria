# alexandria digest — 2026-W37  

Long‑horizon reinforcement learning is getting two complementary pushes.  
First, **Feedback‑Enriched Environments (FEEs)** reshape the observation stream so that agents receive richer, structured hints during training.  The result is steadier learning and broader exploration on tasks that were previously too sparse for standard RL.  
Second, system‑level engineering is maturing.  Papers on **Miles**, **NeoHorse**, **MaxKernel**, and **Gander** show that modular post‑training pipelines, intelligent routing harnesses, and multi‑agent kernel generation can be built at production scale while keeping latency and compute in check.  Together these currents point toward agents that learn faster, stay stable, and can be deployed end‑to‑end without hand‑tuned components.

## Trailblazing  

**FEEs consistently boost self‑evolving agents on long‑horizon benchmarks.**  
What it is: A training setup that injects extra feedback into the agent’s observations, letting the model see hints about its recent actions while solving tasks that require many steps.  
Why it matters: Use FEEs to close the reward‑sparsity gap; agents reach higher scores on SciWorld and BFCL without redesigning the core RL algorithm.  
*Environments as Scaffold: Enriching Feedback to Bootstrap Self‑Evolving Agents in Long‑Horizon Tasks* — [link](https://arxiv.org/abs/2609.08404)

**Consistent intra‑group feedback keeps FEE training stable.**  
What it is: When the extra feedback signals are uniform across a batch of agents, the learning dynamics stay well‑behaved; mismatched signals cause divergence.  
Why it matters: Design your feedback generators to produce group‑level consistency, or risk unstable training runs.  
*Environments as Scaffold: Enriching Feedback to Bootstrap Self‑Evolving Agents in Long‑Horizon Tasks* — [link](https://arxiv.org/abs/2609.08404)

**Miles v0.1 runs a 744 B model with a median step time of 263 s on 64 GPUs.**  
What it is: A production‑grade post‑training stack that orchestrates asynchronous RL loops, leveraging SGLang for rollout execution and supporting both Megatron‑LM and PyTorch FSDP backends.  
Why it matters: The reported step time demonstrates that frontier‑scale RL can be run efficiently on commodity GPU clusters, guiding infrastructure choices for large‑model training.  
*Miles v0.1: Production‑Level Post‑Training* — [link](https://arxiv.org/abs/2609.08368)

**NeoHorse‑1’s routing harness lifts macro‑average scores from 58.94 → 64.87 (4 B) and 65.60 → 69.04 (9 B).**  
What it is: A post‑training loop that routes inputs through a heterogeneous model pool, using evaluation feedback to shape the next training mixture.  
Why it matters: The performance jump shows that intelligent routing can close the gap between smaller post‑trained models and larger base models, reducing the need for ever‑larger pre‑training runs.  
*NeoHorse-1: Towards Recursive Self‑Improvement via Agentic Post‑Training with Routing Harness* — [link](https://arxiv.org/abs/2609.08183)

**MaxKernel’s multi‑agent system builds TPU kernels that match expert hand‑tuned performance.**  
What it is: A collection of specialized sub‑agents (planning, implementation, debugging, profiling) that collaboratively generate and verify Jax kernels, iterating without human input.  
Why it matters: The approach proves that autonomous, multi‑agent pipelines can replace manual kernel engineering, opening the door to self‑optimizing hardware‑software stacks.  
*MaxKernel: Agentic Kernel Generation for TPUs* — [link](https://arxiv.org/abs/2609.04523)

**Gander unifies omni‑perception, real‑time interaction, and agentic reasoning in one model.**  
What it is: An end‑to‑end architecture that streams video, speech, and text inputs continuously, handling both conversational and higher‑level reasoning tasks.  
Why it matters: The design offers a blueprint for building agents that operate across modalities without separate preprocessing stages, simplifying system integration.  
*Omni Interaction Agent Technical Report* — [link](https://arxiv.org/abs/2609.08977)

## Gaining traction  

- **Puffin‑World** – three independent papers now support the claim that a unified 3‑D world state with an Omni‑Camera eliminates the need for external offline modules.  
- **Compile‑by‑Training** – three sources back the idea that natural‑language specs can be compiled into reusable neural functions that run without teacher models at inference.  
- **Inference‑time context management** – three works agree that limiting tool sets, context length, and using a fixed judge yields larger gains than most system tweaks.  
- **One‑shot on‑policy distillation (OPD)** – two papers confirm that training on a single query recovers most of the benefit of full‑data OPD across tasks and model families.  
- **Random Attention** – two studies show that random KV‑cache eviction matches the strongest prior evictors while boosting throughput by 32 %–43 % in vLLM deployments.
