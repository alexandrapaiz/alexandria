# alexandria digest — 2026-W37  

The week’s strongest signals revolve around two ideas. First, shaping the learning signal—whether by enriching feedback, routing evaluation results, or closing the loop between inference and training—has become a reliable lever for boosting long‑horizon performance. Second, system‑level engineering that bundles modular sub‑agents and tight runtime feedback is emerging as the backbone for scalable, production‑grade agents. Both currents appear in the newest claims on Feedback‑Enriched Environments, the Miles post‑training stack, and the NeoHorse routing harness, suggesting that future pipelines will intertwine richer supervision with tighter orchestration.  

## Trailblazing  

**Feedback‑Enriched Environments boost long‑horizon agent performance.**  
Feedback‑Enriched Environments (FEEs) augment the observation stream with additional signals that guide the agent during training. Large‑scale experiments with Qwen‑13 models and several RL algorithms (GRPO, GSPO, DAPO) show consistent gains on the SciWorld and BFCL benchmarks compared with standard settings. When the feedback signals stay consistent within a group, training remains stable; inconsistency leads to divergence, highlighting intra‑group feedback consistency as a stability boundary. Entropy volatility drops noticeably, indicating smoother learning dynamics. Agents also explore broader state regions and retain performance even after the enrichment is removed at test time, meaning the guidance is internalized into policy weights. *Environments as Scaffold: Enriching Feedback to Bootstrap Self‑Evolving Agents in Long‑Horizon Tasks* — [link](https://arxiv.org/abs/2609.08404).  

**Miles v0.1 delivers a production‑grade post‑training stack for frontier‑scale agents.**  
Miles v0.1 is a modular RL training system that supports both NVIDIA Megatron‑LM and PyTorch FSDP backends and offers three weight‑synchronization transports to match diverse deployment topologies. The architecture builds rollout engines on SGLang, providing an efficient execution layer for large‑scale inference. In an end‑to‑end case study, a 744 B GLM‑1.5 model running on 64 NVIDIA GB300 GPUs achieved a median step time of 263 seconds over the first 30 steps, demonstrating practical throughput at scale. The system’s components are verified, clean, and customizable, and the stack supports full‑parameter RL, LoRA‑based RL, on‑policy distillation, supervised fine‑tuning, and even diffusion model training. These capabilities position Miles as a ready‑to‑use foundation for large‑scale post‑training pipelines. *Miles v0.1: Production‑Level Post‑Training* — [link](https://arxiv.org/abs/2609.08368).  

**NeoHorse‑1 routing harness turns evaluation feedback into the next training mixture.**  
NeoHorse‑1 introduces a heterogeneous model pool with an intelligent routing layer that predicts capability demand, selects an appropriate service tier, and records each interaction for continual improvement. Routing signals organize supervised fine‑tuning into a three‑stage curriculum and guide on‑policy distillation, letting a teacher supervise student‑generated responses. By converting evaluation results into a capability‑guided training mixture, the system closes a loop where what the model learns to do shapes what it learns next. This closed loop raises macro‑average performance on eleven benchmarks from 58.94 → 64.87 for a 4 B model and from 65.60 → 69.04 for a 9 B model, narrowing the gap to larger base models. The approach also generates training examples from recorded user turns, applying structural checks, six‑dimensional semantic evaluation, and subscene labeling to ensure data quality. *NeoHorse‑1: Towards Recursive Self‑Improvement via Agentic Post‑Training with Routing Harness* — [link](https://arxiv.org/abs/2609.08183).  

**MaxKernel’s multi‑agent system autonomously generates TPU kernels that match expert hand‑tuned performance.**  
MaxKernel assembles a shared pool of specialized sub‑agents for planning, implementation, self‑debugging, testing, and hardware profiling, enabling both human‑in‑the‑loop and fully autonomous kernel generation. The autonomous metric‑and‑trace driven loop (Auto agent) iteratively measures kernel speed and adjusts the search, delivering notable speedups on the JaxBench benchmark without human intervention. A graph‑based autonomous search paradigm scales this loop to explore the global design space, adding further performance gains on large‑scale workloads. Across 50 diverse JaxBench tasks and real‑world model kernels, the generated kernels achieve performance comparable to expert‑crafted baselines. *MaxKernel: Agentic Kernel Generation for TPUs* — [link](https://arxiv.org/abs/2609.04523).  

**Gander’s omni‑interaction architecture separates low‑latency interaction from complex reasoning.**  
The Gander system splits the runtime into a Cerebellum that handles real‑time interaction and a Brain that performs higher‑level reasoning, linking the two via tool‑calling and an orchestration runtime. Inputs and outputs are flattened into an ordered token stream at the chunk level, creating a unified representation that supports low‑latency duplex communication. This streaming Thinker‑Talker design lets the agent ingest video, speech, and text continuously while maintaining a fast feedback channel for tool use. The architecture demonstrates continuous multimodal interaction without the latency spikes typical of separate perception and planning loops. *Omni Interaction Agent Technical Report* — [link](https://arxiv.org/abs/2609.08977).  

## Gaining traction

Compile‑by‑training converts natural‑language specifications into reusable neural functions that run without teacher models at inference time, also backed by three citations.

## Left behind  

**Contradicted**  
The claim that Claude Opus 5 under Claude Code passes only 23.9 % of 53 evaluation simulations is overturned by an expert‑authored reference implementation achieving 82.2 % success; builders should no longer rely on the lower benchmark as a ceiling.  
The claim that a single ReAct agent without sub‑agents can solve the hardest rollouts is contradicted by a shared executable‑skill interface that combines high‑level skill selection, bounded low‑level VLA execution, and post‑action verification; systems should adopt the skill‑interface architecture for robust performance.  
The claim that the expert‑authored reference implementation reaches 82.2 % success is itself contradicted by results on four memory‑dependent RMBench tasks showing only 12.5 % average success, indicating that the same approach struggles with memory‑intensive workloads.
